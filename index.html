Aturan strategi

BUY: tren EMA20 > EMA50, RSI 50–70, MACD histogram positif, volume ≥ rata-rata 20. SELL: EMA20 < EMA50, RSI < 50, MACD histogram negatif, volume ≥ rata-rata 20. Kondisi lain WAIT. Sinyal dihitung dari candle yang sudah selesai.

Di mode spot, SELL = pertimbangan keluar dari posisi. Di mode futures, BUY bullish ditampilkan sebagai LONG dan SELL bearish sebagai SHORT. Ini sinyal arah, bukan perintah membuka posisi atau ukuran leverage.

Penting: Futures berisiko likuidasi dan kehilangan seluruh margin; level ATR bukan harga likuidasi. Ini alat edukasi/riset, bukan nasihat investasi. Tidak ada jaminan profit. Tidak melakukan order, tidak membutuhkan API key, dan menghitung estimasi fee backtest tetapi tidak slippage. Permintaan data dapat gagal jika Binance membatasi IP server atau wilayah. Funding, leverage, likuidasi, spread dan slippage tidak dihitung.
